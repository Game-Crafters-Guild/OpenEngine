title: Smart folders

Smart folders are virtual folders that show the assets matching a set of filters. They organize and reach files across the project without moving them from where they are.

## Creating a smart folder

1. Right-click the **Smart Folders** section in the Assets panel's tree.
2. Choose **New Smart Folder** from the context menu.
3. A smart folder named "New Smart Folder" appears.
4. Click it to select it, and set it up in the Inspector panel.

## Smart folder settings

With a smart folder selected, the Inspector panel shows these settings.

### Name

The smart folder's display name in the Assets panel's tree.

### Location

The folder to search:

- **(All Assets)** searches every file in the project's assets folder.
- **A folder** limits the search to that folder and its subfolders. The list offers the folders up to three levels deep.

### Match

How several filters combine:

- **Any filter (OR)** includes files that match *any* filter.
- **All filters (AND)** includes only files that match *every* filter.

### Global

Where the smart folder is stored:

- **Off:** in the project; it appears only while this project is open.
- **On:** globally; it appears in every project.

## Filters

Filters decide which files appear in the smart folder. **Add Filter** adds a filter row, and the **×** button at the right of a row removes it.

| Filter type | Matches | Example values |
|---|---|---|
| **File Type** | files by extension | `.png`, `.jpg`, `.cs`, `.mp3` |
| **Name Contains** | files whose name contains the text | `player`, `texture`, `audio` |
| **Regex** | files whose name matches a regular expression | `^UI_.*`, `.*_diffuse$`, `player\d+` |
| **Tag** | assets that carry the tag | a tag from the project's tags |
| **VCS Status** | files in a version control state | `Modified`, `Added`, `Deleted`, `Unversioned`, `Conflict`, `LockedByMe`, `LockedByOthers`, `ServerHasChanges`, `Ignored`, `Clean` |

## Using smart folders

- **View the contents:** click a smart folder in the tree to show its matching files in the grid or list.
- **Open files:** double-click a file in the smart folder's view.
- **Drag and drop:** drag files from a smart folder to other panels.

## Undo

Creating, deleting, and editing smart folders can be undone and redone:

- **Create:** undo removes the smart folder.
- **Delete:** undo restores it with all its settings.
- **Edit:** undo reverts the change to its settings.

Press **Cmd+Z** on macOS or **Ctrl+Z** on Windows and Linux to undo.

## Examples

| Smart folder | Match | Location | Filters |
|---|---|---|---|
| All textures | Any filter (OR) | (All Assets) | File Type `.png`, File Type `.jpg`, File Type `.tga` |
| All audio files | Any filter (OR) | (All Assets) | File Type `.mp3`, File Type `.wav`, File Type `.ogg` |
| Player scripts | All filters (AND) | (All Assets) | File Type `.cs`, Name Contains `Player` |
| UI textures | All filters (AND) | `Assets/Textures` | Regex `^UI_.*` |

## Preferences

The **Assets** page of the editor's preferences has two settings for smart folders:

- **Smart Folders At Top** (on by default) puts the smart folders at the top of the Assets tree. Off puts them at the bottom.
- **Expand Smart Folders** (off by default) expands the smart folders section when the editor starts.

## Where smart folders are stored

- **Project smart folders:** `<ProjectRoot>/.Editor/SmartFolders.json`.
- **Global smart folders:** `SmartFolders.json` in the editor's user data folder: `%APPDATA%\GameEngine\Editor\` on Windows, `~/Library/Application Support/GameEngine/Editor/` on macOS, `$XDG_DATA_HOME/GameEngine/Editor/` (else `~/.local/share/GameEngine/Editor/`) on Linux, or the folder `GE_EDITOR_USER_DATA_ROOT` names.

## How the files are found

Smart folders look files up in the asset registry rather than scanning the file system, so they are fast, follow `.assetignore` rules, and show only registered assets. When the registry lookup yields no candidates (for example while the registry's mappings are being rebuilt), the smart folder scans the file system instead.
