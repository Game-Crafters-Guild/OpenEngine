## Gizmo tools (Scene View)

| Key | Tool | Description |
|-----|------|-------------|
| **Q** | Selection | Arrow tool - select objects |
| **W** | Move | Translate gizmo - move objects |
| **E** | Rotate | Rotation gizmo - rotate objects |
| **R** | Scale | Scale gizmo - resize objects |

## Camera navigation (Scene View)

### Mouse camera controls

| Input | Action | Description |
|-------|--------|-------------|
| **RMB (Hold & Drag)** | FPS Look | Free-look camera (first-person style) |
| **Alt + LMB** | Orbit | Rotate camera around pivot point |
| **Alt + Ctrl + LMB** (PC/Linux) | Pan | Move camera horizontally/vertically |
| **Alt + Cmd + LMB** (macOS) | Pan | Move camera horizontally/vertically |
| **Alt + RMB** | Dolly | Zoom in/out (move left-right) |

### Keyboard camera controls

| Input | Action | Description |
|-------|--------|-------------|
| **W** (+ RMB) | Move Forward | Move camera forward |
| **A** (+ RMB) | Move Left | Move camera left |
| **S** (+ RMB) | Move Backward | Move camera backward |
| **D** (+ RMB) | Move Right | Move camera right |
| **Shift** (+ WASD + RMB) | Fast Move | 3x faster camera movement |

### Camera framing

| Key | Action | Description |
|-----|--------|-------------|
| **F** | Frame Selection | Focus camera on selected object |
| **Alt + F** | Frame All | Focus camera on all objects in scene |

In perspective views, framing fits the object's bounds in the view with a small margin, and the
camera then orbits around the object's center. The camera moves into place with a short
transition. An object whose thinnest side is less than a tenth of its largest is flat, such as a
floor with everything that stands on it. A flat object seen at less than 30 degrees from its plane
is viewed from 30 degrees above or below it: from below only when the camera is below it, and from
above otherwise. The Scene View draws at least
twice as far as the camera is from its orbit center, so a large object stays visible from the
distance that frames it. The Far Clip setting keeps its value.

## Global editor shortcuts

| Key | Action | Description |
|-----|--------|-------------|
| **G** | Toggle Gizmos | Show/hide transformation gizmos |
| **P** | Toggle FPS Counter | Show/hide FPS counter in Scene View |
| **Cmd + W** (macOS) | Close Tab/Window | Close active tab or floating window |
| **Ctrl + W** (PC/Linux) | Close Tab/Window | Close active tab or floating window |
| **F11** | Toggle Debug Zones | Show/hide dock debug overlay |

### Diagnostics

| Key | Action | Description |
|-----|--------|-------------|
| **F2** | CPU Profiler | Turn the CPU profiler on. Press again to print the last frame's scope summary to the log |
| **Shift + F2** | CPU Profiler Off | Turn the CPU profiler off |
| **F3** | UI Demo | Open the UI demo panel |

The CPU profiler keys exist in builds with CPU profiling compiled in. When the Hierarchy or the
Assets panel has keyboard focus, **F2** renames instead. All three can be rebound under
**Keyboard Shortcuts > Diagnostics**. While a game runs in a focused Game View, a game that binds or
reads one of these keys receives it and the editor does not act on it. A key the game does not use
still reaches the editor.

## Hierarchy and Assets panel

These keys act on the selection of the panel that has keyboard focus. Click an item in the panel
first.

| Key | Action | Description |
|-----|--------|-------------|
| **F2** | Rename | Rename the selected entity in the Hierarchy, or the selected asset or folder in the Assets panel (its item view or its folder tree) |
| **Return** (macOS) | Rename | The same as F2, as in Finder |
| **Delete** | Delete | Delete the selected entities in the Hierarchy, with their children |
| **Ctrl + D** (PC/Linux), **Cmd + D** (macOS) | Duplicate | Duplicate the selected entities in the Hierarchy |

While you rename, **Enter** keeps the new name and **Escape** cancels. A name that cannot be used
is outlined in red as you type, a note under the field says why (for example, that another file in
the folder already has the name), and Enter leaves the field open. A click outside the field keeps
a name that can be used and cancels one that cannot.
Two entities can have the same name. The context menus of both panels list Rename and Delete as well,
with their keys. In both panels, a slow second click on the name of the selected item also starts a
rename.

## Log panel

These keys and clicks act on the lines of the Log panel. Click a line first to give the list
keyboard focus.

| Key or click | Action | Description |
|--------------|--------|-------------|
| **Click** | Select | Select the line and show its whole message, time, source and stack trace in the detail pane |
| **Shift + Click** | Select Range | Select every line from the last selected line to this one |
| **Ctrl + Click** (PC/Linux), **Cmd + Click** (macOS) | Add to Selection | Add the line to the selection, or take it out |
| **Ctrl + A** (PC/Linux), **Cmd + A** (macOS) | Select All | Select every line the filters show |
| **Ctrl + C** (PC/Linux), **Cmd + C** (macOS) | Copy | Copy the selected lines, each with its source and stack trace |
| **Double-click** | Open Source | Open the file and line the entry names; on a line that names none, a double-click only selects it |
| **Right-click** | Menu | Open the line's menu: Copy, Open Source (on a line that names a file and line) and Clear Log |

A notice at the right end of the copied line confirms each copy. Open Source opens a C# file in the script editor at the
line. It opens any other file in the external editor, at the top of the file.

## View navigation

| Input | Action | Description |
|-------|--------|-------------|
| **Ctrl + Scroll** (PC/Linux), **Cmd + Scroll** (macOS) | Resize Items | Over the Hierarchy or the Assets panel's items, or over the panel's size slider: wheel up makes the items bigger, wheel down smaller |

Resize Items can be rebound under **Keyboard Shortcuts > View Navigation > Resize Items**. The
binding must include a modifier, so a plain wheel always scrolls. The size slider's tooltip names
the current binding. In the Assets grid, sizes step on a 16 px grid (32, 48, 64, ... px), the same
sizes a drag on the slider reaches. See [UI control defaults](../ui/ui-control-defaults.mdx) for how
the gesture reaches game UI grids.

## Platform differences

All shortcuts work cross-platform. The only difference is:
- **macOS** uses **Cmd** (Command) as the primary modifier
- **Windows/Linux** uses **Ctrl** (Control) as the primary modifier

## Tab management

| Action | Method | Description |
|--------|--------|-------------|
| **Close Tab** | Right-click on tab | Close a specific panel tab |
| **Close Tab** | **Cmd/Ctrl + W** | Close the currently active tab |
| **Close Window** | **Cmd/Ctrl + W** (when no tabs) | Close floating window |

:::note
Tabs have no close button: right-click a tab or use the shortcut to close it.
:::

---

## Tips

- **WASD navigation** requires holding the right mouse button (RMB)
- **Alt-based camera controls** work independently and do not require RMB
- Press **Shift** while moving to triple your movement speed
- Press **F** to quickly frame and zoom to a selected object
- Press **Alt + F** to frame all objects in the scene
- **Right-click on any tab** to access the context menu with close option
- **Cmd/Ctrl + W** closes the active tab. If no tabs remain in a floating window, it closes the window
