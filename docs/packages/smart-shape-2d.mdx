title: Smart Shape 2D
description: Create spline-authored 2D terrain and paths with the separately maintained Smart Shape 2D package.
---

Smart Shape 2D is maintained as a separate package. Its source, sample scenes, textures, licenses, and illustrated authoring manual live in the package repository.

- [Organization package repository](https://github.com/Game-Crafters-Guild/SmartShape2D)
- [Contribution source and installation instructions](https://github.com/larssteenhoff/SmartShape2D)
- [Illustrated authoring manual](https://github.com/larssteenhoff/SmartShape2D/blob/main/docs/authoring.mdx)

The package is pending integration of its engine prerequisites and initial publication in the organization repository. Use the contribution repository's compatibility notes before installing it.
