Smart Shape 2D is a separate native package for spline-authored terrain and paths, textured borders, point anchors, collision, and runtime destruction.

- [Package source and installation instructions](https://github.com/Game-Crafters-Guild/SmartShape2D)
- [Illustrated authoring manual](https://github.com/Game-Crafters-Guild/SmartShape2D/blob/main/docs/authoring.mdx)
- [Example scenes and materials](https://github.com/Game-Crafters-Guild/SmartShape2D/tree/main/Samples/GardenWorlds)

The package requires engine prerequisites that are still under review. Check the package's compatibility notes before installing it.
